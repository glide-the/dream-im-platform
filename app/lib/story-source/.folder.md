# Admin Story source read contract

- 本目录只通过共享 PostgreSQL 查询 Dream 维护的 Workspace、Project/Story 与 Workflow Run；不扫描或写入 Artifact。
- Dream 工作空间展示标题以 `story_workspace_stories.title` 为 canonical 来源；Run 尚未形成 Story 投影时，列表只回退到 Source Message 的 launch goal 前 80 字符。
- Admin 只读取该派生标题用于分页、搜索、列表和详情，不把标题写回 Workflow Run，也不形成第二个 Project 标题真源。
- 所有字段继续受 Story RBAC、查询 allowlist、分页和排序合同约束。
