# Provider auth domain

This folder owns durable, Provider-specific authentication lifecycle work shared by Admin and Gateway.

- `revocation-jobs.ts` is the encrypted revocation outbox for Codex, xAI, and GitHub Copilot grants.
- Protocol endpoints and token parsing remain in `app/lib/providers/**`.
- Admin routes remain thin orchestration in `app/api/admin/**` and `app/lib/admin/**`.
- Secret material must never appear in projections, logs, audit metadata, URLs, or response DTOs.
- Revocation jobs use Provider→job lock order, PostgreSQL DB-clock revision/lease CAS, an immutable source revision in envelope AAD, and exact system-audit idempotency keys. Remote failure retains encrypted material for explicit revision-fenced retry; terminal `succeeded` or `unsupported` clears every envelope field.

Do not turn this folder into a generic queue or a second authentication platform.
