# Server domain contracts

Reuse existing admin/gateway/billing/product modules. `auth` is sole identity/grant authority, `dream` is Admin-owned named data services and typed repositories/UOW. Shared pure resource DTO validators preserve existing policy rules. ORM entities do not cross API DTO boundaries; bigint IDs are exact decimal strings, PG timestamps preserve microseconds. No environment-name business path, startup DDL or persistence fallback.
