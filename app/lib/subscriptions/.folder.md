# Subscription domain contract

- 本目录是订阅 Plan、Version、Entitlement、用户周期、Allowance 与生命周期状态机的服务端来源；Route Handler 只做请求编排。
- 所有写操作必须使用严格 Zod、PostgreSQL 事务、幂等键、乐观版本与 Admin Audit/Subscription Event；终态历史、Token 流水和账本只追加。
- 每个用户同一时刻最多一条可调用订阅。重复开通必须返回可识别的 `SUBSCRIPTION_ALREADY_CALLABLE` 409；新的套餐通过新的开通请求创建，历史 `expired/cancelled` 订阅不阻止重新订阅。管理员取消立即结束当前套餐并进入不可用的 `cancelled` 状态；平台不提供续约、暂停、恢复或期末撤销入口。
- 修改领域合同时同步更新文件头、`docs/design/modules/03-subscriptions.md`、单元测试与隔离 PostgreSQL E2E；禁止增加 SQLite 或内存回退。
