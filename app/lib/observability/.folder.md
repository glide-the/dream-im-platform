# Observability boundary

`capacity.ts` forwards trusted identity and bounded lifecycle observations to the server-owned observer. It exports no credential, body, SQL or user identifier to metric labels. The same business path runs with or without an observer; an observation failure never retries a business operation. Runtime collection, policy, dashboards and operational receipts remain owned by the Notion runbook and server deployment.
