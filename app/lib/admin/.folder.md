# app/lib/admin — Folder Contract

- 本目录承载 Admin Session/RBAC 后的服务端资源校验、事务、SQL 与审计；`app/api/admin/**` Route Handler 保持薄层。
- `claude-plugin-marketplaces.ts` 是平台全局 Remote Marketplace 控制面：严格 Zod、精确 capability、HTTPS host allowlist、临时 Git checkout、immutable revision/entry、批准/阻断与审计。
- `claude-plugin-marketplaces.test.ts` 锁定 URL/ref 校验、manifest 解析与完整内容 digest；`claude-plugin-marketplaces.integration.test.ts` 以显式开关读取公开 Comfy Git，复用同一生产 inspector 且不写业务数据库。
- Remote Marketplace v1 只接受仓库内相对目录插件 source；符号链接、路径逃逸、凭据 URL、非 allowlist host、并发同步和无完整插件 digest 的批准请求全部 fail closed。
- 同步目录在任务结束后删除；业务表只保存 URL/ref/commit/manifests/digests/validation/policy，不保存临时路径、bucket key 或用户 scope。
