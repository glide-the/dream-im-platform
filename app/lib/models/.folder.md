# Model resolution and request header contract

- `resolver.ts` 从 PostgreSQL 当前有效配置解析模型、Provider 与计费价格；调用方复用该结果，不另建模型身份或存储路径。
- `request-headers.ts` 严格校验并规范化模型差异请求头；认证、内容封装与转发 Header 由 Gateway 管理。
- 托管请求先合并模型配置，再合并 Provider-owned Header。仅 Codex 的 `user-agent` 与 `version` 允许模型显式覆盖原生客户端默认值；没有配置就使用默认值。账号、Authorization、originator 与其他产品 Header 继续归 Provider 所有。
- Admin 最小模型验证、Gateway 首次请求与一次 401 续期重放必须复用同一合并函数；客户端兼容性覆盖不改变 Device OAuth 绑定、credential revision、auth epoch 或 registration fingerprint。
- `request-headers.test.ts` 使用纯内存输入验证 DTO、覆盖优先级与 Provider 身份边界，不使用真实凭据或数据库。
