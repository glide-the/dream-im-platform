# PostgreSQL schema contract

- `schema.ts` 与 `schema/**` 是指向 `packages/db/src/schema/**` 的兼容 facade；唯一 Drizzle schema 来源、连接池、内嵌 PostgreSQL 与 migration runner 均由 `@ink-memory/db` 拥有。
- 默认业务阈值必须来自版本化 policy 配置，并通过新增前向 migration 落库；已记录 migration、snapshot、tag、when 与 hash 永不修改。
- 全量业务数据回填不得塞进 schema migration，必须使用 `drizzle/data/**` 的显式、可审计 runner，并先在具名隔离 PostgreSQL 验证。
- schema 变更必须同步更新文件头/目录合同、migration contract tests、文档与数据库 capability 证据。
- `claude-plugin-marketplace-schema-contract.test.ts` 校验五张全局表、不可变/并发约束、零用户 scope、无对象存储关系和精确 capability metadata。
- `dream-managed-mcp-schema-contract.test.ts` 校验四张 MCP 关系、NULL-safe scope、密文凭据边界、可保留的成功导入指纹和精确 capability hash。
- `claude-agent-resource-observer-schema-contract.test.ts` 校验 latest-instance snapshot 列、时间/JSON 约束、heartbeat index、0040 journal 与精确 capability hash。
- `claude-code-runtime-schema-contract.test.ts` 校验 `ai_models` 两个 nullable positive int4 字段、0041 additive migration/journal 与 exact Runtime capability；Dream 不拥有 DDL。
- `chat-history-keyset-pagination-schema-contract.test.ts` 校验 0042 的 `chat_message(thread_id, created_at DESC NULLS LAST, id DESC NULLS LAST)` 索引、非覆盖大 JSON 边界、journal 与 exact Dream capability。
- `chat-history-final-projection-schema-contract.test.ts` 校验 0043 的 additive final 投影、精确 capability、默认 dry-run 回填安全边界与严格 final 判定。
- `provider-managed-accounts-data-contract.test.ts` 校验 0047→显式 runner→0048 的 Provider AAD 到 account AAD 重加密、identity HMAC、dry-run/事务/锁、attempt 清理、revocation quiescence 和脱敏收据合同；`provider-managed-accounts-migration-workflow.test.ts` 锁定根迁移入口、提交后日志和单一 target 生命周期。
- `provider-owned-credentials-data-contract.test.ts` 校验 0049→显式 runner→0050 的 effective-binding ownership、共享/孤儿/工作队列 fail-closed、零 token transform、owner-aware FK、live Provider 唯一性与历史保留合同。
