# Provider product protocol contract

<!-- [Sync] 2026-09-04: align product metadata and isolate bounded model-catalog response budgets. -->

- 本目录是纯协议与产品注册表；不读写 PostgreSQL，不持久化 token，也不拥有 Admin、Gateway 或加密 envelope。
- `http.ts` 的 `readResponseText` 与 JSON 解析复用同一有界字节读取器；默认 64 KiB，模型目录显式使用既有独立预算，超限取消流，读取后释放锁。文本只交给调用方做安全投影，不直接进入公开协议错误；Admin 模型验证复用此读取器获取脱敏后的失败原因。
- `codex`、`xai`、`github_copilot` 是不同资源产品。静态 API Key、普通 HTTP Bearer 与托管 OAuth 不得互相推断。
- Codex、xAI、GitHub Copilot 使用与固定 cc-switch commit 一致的公开原生客户端元数据作为代码默认值，管理员无需注册 OAuth 应用；具名环境变量只做整组产品元数据的显式升级/覆盖，仍须通过相同校验。
- Codex 模型可以通过既有差异 Header 显式设置推理请求的 `user-agent` 与 `version`，由 `models/request-headers.ts` 在默认 Header 后合并；这属于模型客户端兼容性配置，不修改本目录 OAuth registration、绑定指纹、账号或 token，也不开放其他 Provider-owned Header 的覆盖。
- 产品所需最小 scope 在协议边界校验；token 响应显式返回 scope 时必须覆盖当前产品配置的 required scopes，否则拒绝生效并移交撤销。Device Flow 可启动不等于账号拥有资源 entitlement。
- 显式覆盖无效、加密/identity pepper 不可用或 Endpoint policy 无效时 readiness 和所有网络操作 fail closed；普通 GitHub OAuth 成功不等于 Copilot 已连接。
- GitHub Device Flow 不依赖 client secret；只有显式配置匹配 OAuth App 的 secret 时才声明远端 revoke capability，否则本地断开成功但远端结果明确为 `unsupported`。
- Endpoint override 只属于部署配置；所有 endpoint 均要求 HTTPS、443、无 userinfo/query/fragment，并受产品与用途的固定 host allowlist 约束。
- 测试只能通过显式配置、`fetch` 和 clock 注入改变协议输入，生产模块不得按 `NODE_ENV` 分叉。
- 公开错误仅包含稳定 code、类别、可重试性和 HTTP status；不得包含 access/refresh/device token、client secret、上游正文或 Authorization header。
- 账户模型目录必须通过各产品具名 `models` endpoint 获取，输出仅限规范化 ID、显示名、vendor、上游方言、Gateway 兼容性和能力白名单；不得回传原始上游对象。模型目录可使用独立的 8 MiB 字节上限，OAuth discovery/device/token/identity/refresh/revoke 响应仍保持 64 KiB 上限；Admin 规范化层另保留 5000 条模型上限。
- Codex、xAI、Copilot 模型响应形状和兼容性规则彼此独立；live catalog 不得被当作静态运行能力目录，授权成功也不隐式触发 catalog 请求。
- Token rotation 由本层返回完整新 bundle；一旦签发长期 grant，本层同时提供产品最小、不可 JSON 序列化的 `RevocationHandoff`（Codex/xAI refresh token，Copilot source access token）。持久化层必须在任何拒绝/CAS loser 路径持久化 handoff，并用自己的 revision/CAS 和加密 envelope 原子提交有效 bundle。
- Codex/xAI 资源方言为 OpenAI Responses；GitHub Copilot 资源方言为 OpenAI Chat，三者不得因 URL 相似而互换。

`upstream-usage.ts` 提供 OpenRouter Key 支出/额度、DeepSeek 原币种余额、Codex rate window、Copilot 请求额度/不限量的严格语义解析。缺字段不是0，不把窗口限流当订阅金额；固定指标标签、服务端 Header、禁止 redirect 和有界响应，无数据库回退或 raw body 回显。

产品 adapter 的可选 `getUsageAccess` 使用各自 client profile 与来源 token；usage Endpoint 由现有 `config.ts` 的具名覆盖管理，在查询边界验证 host/purpose。错误 usage 覆盖不影响推理/登录或 registration fingerprint；Gateway broker 只做 owned credential fence 后委托 adapter。

Codex 默认 wire `resourceClientVersion` 与 catalog `modelCatalogClientVersion` 同步 cc-switch `d0b57827` 的 `0.159.0`；OAuth registration 的既有 `integrationVersion` 与指纹继续保留原值，升级请求兼容性不撤销已绑定账号。具名 `INK_PROVIDER_CODEX_RESOURCE_CLIENT_VERSION` / `INK_PROVIDER_CODEX_MODEL_CATALOG_CLIENT_VERSION` 可覆盖；原 `INK_PROVIDER_CODEX_INTEGRATION_VERSION` 显式覆盖仍保留原语义并作为未单独指定 wire 版本时的默认。模型 request Headers 在该默认值之后合并。
