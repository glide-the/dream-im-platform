# Public Gateway route contract

<!-- [Sync] 2026-10-09: document direct Images routes beside existing text-compatible Gateway entrypoints. -->

- `images/generations` 与 `images/edits` 是独立 Images 入口，只负责把 Web Request 交给 `app/lib/gateway/image-handler.ts`；认证、授权、校验、Provider 调用、结算和错误投影均留在领域层。
- Image 请求不进入 Messages/Chat/Responses 转换链，不保存 prompt、参考图、输出 base64 或上游原始正文。
- 新增公开入口必须同步更新 Gateway 目录、权限合同、请求记录和聚焦回归。
