# Admin components contract

- 本目录只承载管理端交互与 Refine 数据编排；服务端授权、校验、事务和审计必须留在 `app/lib/**`。
- `SubscriptionLifecycleManager.tsx` 的首次开通与既有订阅生命周期动作必须分开：既有订阅换套餐走下周期 `upgrade/downgrade`，取消走 `cancel_at_period_end`，不得用重复创建模拟切换。
- 可调用订阅行必须明确展示“更换套餐”和“期末取消”；高风险动作仍通过带原因的确认 Dialog 提交，客户端按钮隐藏不作为授权边界。
- 修改组件时复用现有 Admin chrome、设计 Token、可访问 label/focus 和服务端分页合同，并同步更新对应交互文档与测试。
