# App folder contract

Next.js hosts protected Refine Admin, Better Auth `/auth` interactions for Dream OAuth subjects, and thin Admin/auth/internal Dream/Gateway resource ingress. `/admin` uses its independent `admin_users/admin_sessions/RBAC` boundary; a Dream Better Auth Session or OAuth token is never management authority. All complex validation/persistence/audit stays under `app/lib`, all DDL in canonical Drizzle history; PostgreSQL only. Sync 2026-09-17.

<!-- [Sync] 2026-10-05: Provider upstream usage and revisioned same-model routing. -->

Provider 页面支持服务器查询的上游账户指标；独立 `/admin/routing` 菜单管理同模型多 Provider 策略。Gateway 公开入口、Alias 身份和价格所有权保持一致。

<!-- [Sync] 2026-10-10: independent Image model-center information architecture. -->

`/admin/image-models/**` 与 AI 模型中心并列，只提供 Provider、Models、Pricing 配置，不挂请求记录或账单入口；同一资源、权限、价格和账本继续复用。Image 调用日志归属 `/admin/gateway/requests`，用量/费用归属 `/admin/billing/usage`。旧 Image 请求 URL 仅跳转到 Gateway 日志，不保留独立记录页面。Sync 2026-10-10.
