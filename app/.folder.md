# App folder contract

Next.js hosts protected Refine Admin, Better Auth `/auth` interactions for Dream OAuth subjects, and thin Admin/auth/internal Dream/Gateway resource ingress. `/admin` uses its independent `admin_users/admin_sessions/RBAC` boundary; a Dream Better Auth Session or OAuth token is never management authority. All complex validation/persistence/audit stays under `app/lib`, all DDL in canonical Drizzle history; PostgreSQL only. Sync 2026-09-17.
