# Dream browser authentication entry

| Folder | Method | Behavior |
| --- | --- | --- |
| `password/` | `POST` form | Exact-origin login/register DTO invokes Better Auth email APIs and returns to Dream PKCE. |
| `google/` | `POST` form | Exact-origin request invokes Better Auth `socialProviders.google` and follows its provider state/callback. |

Inputs reject absolute returns, duplicate/unknown fields and unconfigured origins. Browser credentials are sent directly to Admin and never appear in a Dream request, response, log or persistent store. These routes create Dream authentication Sessions only; Admin operator login and RBAC remain separate.
