# Unified authentication pages

`sign-in`, `consent` and `device` provide the Admin-owned login and OAuth/device authorization experience. They reuse Better Auth's installed browser plugins and same-origin session routes. Password registration and Google login remain available. Consent display validates provider-signed context and registered client data; actual grants always go through the provider endpoint.

The browser receives no service secret or API token. Device approval retains the installed pending/approved/denied state machine. Admin management permissions remain independent of login. See [contract](../../docs/architecture/admin-dream-auth-data-contract.md).
