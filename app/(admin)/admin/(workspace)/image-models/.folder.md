# Image model-center route contract

- `/admin/image-models` 默认进入 Models；Provider、Models、Pricing 是本中心的三个一级栏目，与 AI 模型中心并列。
- 新建、编辑、调价复用共享注册表和全页表单，返回及保存后导航保持本中心上下文。
- 本中心没有请求记录或账单入口。`requests/page.tsx` 仅兼容旧书签并重定向 `/admin/gateway/requests`；所有请求排查和费用查看归属既有日志/计费模块，不渲染独立表格。
- Provider 仅显示 Codex 和显式标记 Image API 的 OpenAI 连接，模型/价格仅显示 Image-capable 资源。
- Provider 页面直接使用共享连接列表，不显示额外就绪汇总。Pricing 保留同款 models.dev 同步按钮；`pricing/sync/[snapshotId]` 复用 `PricingSyncReview`，重新同步、应用和取消均留在 Image 中心。
- 旧 `/admin/models/images` 只做兼容重定向；不得再挂入 AI 中心导航。不得复制权限、凭据、资源 API、数据表或账本。
