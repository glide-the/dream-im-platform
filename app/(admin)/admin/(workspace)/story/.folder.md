# Admin Story routes contract

- 本目录只组合 Story Workspace、canonical Story 与 Dream Workflow Run 的 Admin 只读运营页面；业务查询和授权留在 `app/lib/story-source/`。
- Story 与 Workflow Run 列表统一显示 Dream 工作空间标题：canonical `story_workspace_stories.title` 优先，只有 Project 尚未构建时才回退 launch goal 前 80 字符。
- 页面不得扫描 Artifact、修改 Dream Project/Episode 文件、写 Workflow Run 标题或建立第二套 title truth source。
