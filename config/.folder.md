# Versioned policy configuration contract

- 本目录保存需要被 schema、应用与运维 runner 共同读取的非 Secret 平台策略；禁止放置凭证、DSN 或用户数据。
- 429 Token 默认阈值以 `gateway-default-limits.mjs` 为唯一配置来源；修改 revision 或数值时必须新增前向 Drizzle migration 与显式数据 runner。
- 配置值必须是确定、可审计的安全整数；部署环境名称不得改变业务策略。
- `claude-plugin-marketplace-policy.mjs` 集中定义 Remote Marketplace Git host allowlist、同步超时和仓库/manifest/条目边界；不保存来源 URL、凭证或对象存储配置。
