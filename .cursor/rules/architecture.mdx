# Architecture

依赖方向：Admin pages/components → protected API → domain modules → PostgreSQL/providers。

- UI 不直接访问数据库。
- API 只解析、调用领域函数并标准化响应。
- Admin 写操作必须校验 Session/RBAC/Origin/Zod 并记录审计。
- Story/System 自有资源可以受控 CRUD；财务、usage、audit 只读/只追加。
- Provider 凭据加密，Gateway Key 哈希，敏感配置读取脱敏。
- 网关失败必须进入可解释终态，未知 usage 不按零费用猜测。
