# Ink Memory Admin v3：页面结构草图与模块索引

> HTML Design Workflow / Stage 2 — Structure Sketch Designer
> 输入：`files/workspace/1_prd_draft.md`、`files/inputs/target_image.png`、`files/inputs/topic.txt`
> 目标视口：Desktop `1440×1000`；Mobile `390×844`
> 结构性质：B 端运营控制台，不是 Landing Page；所有 `{…}` 均代表真实 API / PostgreSQL 返回值，不代表假数据。

## 0. 本阶段 Prompt Architect 记录

**Optimized Prompt：**基于 Stage 1 PRD、UI v2.1 封面及主题，为 Ink Memory Admin v3 生成可直接指导后续 UI 设计与实现的中文 ASCII 页面结构草图。草图必须围绕真实 Dream 数据与订阅计费任务，覆盖统一 Admin Shell、User → Workspace → Story → Character/Scene、Plan → immutable Version → Entitlement、用户订阅详情与周期额度、Provider → Model → Pricing、Gateway Request → Usage → Allowance/Balance → Ledger，并分别表达 1440×1000 与 390×844 的信息重排。每个结构块使用稳定 ID，提供完整模块索引；不得画品牌 Landing Page、不得使用假指标、不得展示 Secret 明文、不得用卡片墙代替信息架构。

**Optional Enhancers：**月度账单预览与安全 CSV 导出入口；支付适配器状态仅显示“未接入/已配置”，不模拟支付；关键状态机操作在结构中保留影响摘要、幂等键与冲突恢复位置。

## 1. 结构语言与全局约束

- 页面视觉取自封面可验证特征：暖纸画布、大面积留白、深炭棕标题、暖棕正文、轻纸面分区、视觉收敛。
- 每个页面最多一个 `┈┈` 表示的 page-level 虚线 Paper Boundary；内部只用留白与细分隔线，不叠加圆角卡片墙。
- `{真实值}`、`{真实状态}`、`{真实总数}`、`{服务器时间}` 均由 API 返回；不可用时显示“暂不可用 + request ID”，不以 `0` 代替。
- Secret 仅允许 `{已配置}`、`{未配置}`、`{一次性回执}` 三种结构语义；草图中不放示例 Token。
- 桌面根节点只有一个主滚动区；表格内部可横向滚动。移动根节点不得超过 390px，详情、编辑和筛选层均全屏或底部 Sheet。
- Desktop 信息顺序：上下文 → 查询 → 主事实 → 关系/解释 → 操作。Mobile 信息顺序：身份/状态 → 关键原因 → 可操作项 → 次级事实。

## 10. 状态、错误与高风险覆盖层

```text
┌──────────────────────────── [X1 主事实区原位状态替换] ────────────────────────────┐
│ loading：保留表头/筛选/最终行高 skeleton                                         │
│ empty：区分“无数据”与“筛选无结果”；只读域不诱导创建                              │
│ 401：登录后返回原 URL                                                            │
│ 402：额度/余额不足，跳转订阅或余额详情；不鼓励重试消耗请求                        │

│ 404：返回对应列表                                                                │
│ 409：服务器最新状态 + Diff；保留草稿，禁止盲目覆盖                               │
│ 429：限制来源 + 重置时间                                                         │
│ 503：缺表/依赖与 request ID；绝不回退旧表或假数据                                │
└───────────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────── [X2 高风险确认] ─────────────────────────────────────┐
│ 动作及不可逆/延迟影响摘要                                                        │

```
