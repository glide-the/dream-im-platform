Ink Memory Admin：剧本数据运营与用户、权限、资源管理后台

当前 `target_image.png` 是 1440×1000 Admin 基线，用于提取侧栏、暖纸画布、主纸面、页头、表格和响应式结构，不是默认 Refine/Ant Design 模板。

本轮唯一范围：
1. 运营总览；
2. Workspace 列表、详情、创建、合法编辑和归档；
3. Story 列表、详情、合法字段编辑、审核与归档；
4. 平台用户列表、详情、状态维护及关联 Workspace/Story；
5. 管理员、角色、权限矩阵；
6. Storage 文件列表、筛选、上传、预览、下载、删除和审计；
7. 审计日志。

设计依据：
- docs/prd/story-user-resource-admin-prd.md
- docs/verification/story-user-resource-admin-audit.md
- docs/prd/Ink & Memory UI Design v2.pdf
- docs/prd/color_system/*
- docs/design/admin-ui-visual-specification.md

视觉必须使用“暖纸张、手写笔记、安静工具台”：Light/Dark 语义 Token、页面级单一虚线 paper boundary、内部留白与行分隔线、静止列表无阴影、黄色/绿色仅小面积 accent。禁止蓝紫 AI、冷灰企业后台、霓虹、多层卡片海和默认 CRUD 外观。

必须给出：
1. 1440×1000 与 390×844 的完整结构草图；
2. User → Workspace → Story 与 RBAC/Storage/Audit 的跳转；
3. 服务端分页、筛选、排序、URL 恢复、详情返回与焦点恢复；
4. loading、empty、error、403、404、409、Storage 未配置；
5. Workspace settings JSON 与 Story 长文本的安全可读展示；
6. 删除、停用、归档、权限变化的二次确认；
7. 可见 Label、键盘、焦点锁定、live region、prefers-reduced-motion；
8. 集中 CSS variables / Tailwind 4 Token，禁止组件散落孤立色值。

模型、计费、网关只保留现状，不进入本轮设计；禁止数据迁移、同步、第二数据库、SQLite、app/(app)。
