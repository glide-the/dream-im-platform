# docker/

## 架构概述

Admin/Gateway 与内嵌 PostgreSQL 的容器镜像和本地 Compose 入口。阿里云编排位于
`deploy/remote-ssh/`，复用同一镜像但不把 PostgreSQL 映射到 host。

## 文件清单

| File | Pos | Function |
|------|-----|----------|
| `Dockerfile` | 应用镜像 | 串行构建 Next.js/runner，配置 mirror，预建 native aliases，打包 DB runtime/client |
| `entrypoint.sh` | 容器入口 | 修复 volume 权限后以非 root 启动 DB supervisor；拒绝 `RUN_DB_MIGRATIONS=true` |
| `compose.yml` | 本地编排 | 单 Admin 容器，内嵌 PG 映射到 localhost:5433；MinIO 不存在 |
| `.env.example` | 本地配置模板 | `pnpm env:setup` 的 Docker 环境模板 |
