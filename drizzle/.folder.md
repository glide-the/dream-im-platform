# drizzle — Folder Contract

- 本目录是 `@ink-memory/db` 管理的唯一前向 SQL/journal/snapshot 历史；TypeScript schema 位于 `packages/db/src/schema/**`，历史条目一旦发布不得修改。
- `0037_claude_plugin_remote_marketplace.sql` 是 Remote Marketplace 的 expand owner：五张全局表、operation/installation lineage、不可变 trigger、完整插件 digest、单 running sync、Admin permission 与精确 Dream capability。
- 0037 不 seed 任何 Marketplace 来源、业务插件或用户数据，不创建对象存储表，也不引入 runtime DDL/SQLite fallback。
- `0038_dream_managed_mcp_resources.sql` 是 Dream-managed MCP expand owner：四张用户/工作区 scope 关系、密文凭据、发现快照、持久导入回执与精确 capability；不含 Admin permission、runtime DDL 或明文凭据。
- `0039_claude_agent_resource_rbac.sql` 只幂等补齐 `system.read/system.write` 和 super_admin/operator/auditor 精确授权；不新增资源策略表或 seed 业务配置。
- `0040_claude_agent_resource_observer.sql` 只新增 latest-instance snapshot 表、时间/JSON 约束、heartbeat index，并在 DDL 之后发布 `dream.claude-agent-resource-observer.v1`；不修改 0039 或 `system_settings`。
- `0042_chat_history_keyset_pagination.sql` 只新增 `chat_message` 稳定倒序 keyset 索引，并在索引之后发布 `dream.chat-history-keyset-pagination.v1`；保留旧索引且不覆盖 `parts`/`metadata`。
- `0043_chat_history_final_projection.sql` 只新增 assistant final/process/version 投影列及行约束，登记显式回填 runner 后发布 `dream.chat-history-final-projection.v1`；migration 不扫描或改写业务正文。
- `0044_serious_red_wolf.sql` 只为 `ai_providers` 增加单调 `auth_revision` 与 exact `unverified/valid` credential validation metadata；存量行初始化为 revision 1、unverified、NULL，不修改 status、密文或 Gateway readiness，也不创建 OAuth token/attempt 表。
- `0045_abandoned_killraven.sql` 扩展 Provider adapter/credential-kind/auth-epoch 状态，新增密文 managed credential 与一次性 auth attempt 表，并为 Gateway 请求保存非秘密鉴权快照；产品 adapter 不存可编辑 base URL，0044 的静态 API key 字段保持不变。
- `0046_lovely_hemingway.sql` 新增 Provider 专属持久撤销 outbox：凭 source revision/auth epoch 防串线、revision/lease 做单任务 CAS，覆盖 disconnect/replacement/activation-rejected/renewal-rejected 孤儿 grant，失败保留独立重加密 envelope 以便重试，成功或 unsupported 后强制清除密文；不建立通用 job 框架。
- `0047_provider_managed_accounts_expand.sql` 登记默认 dry-run 的 `provider-managed-accounts.ts`；`0048_provider_managed_accounts_contract.sql` 仅在其 committed 收据、account AAD、HMAC identity、Provider binding、terminal attempt/revocation quiescence 均验证后解除旧 Provider ownership。
- `0049_provider_owned_credentials_expand.sql` 放宽 pinned/null 过渡状态并登记 `provider-owned-credentials-v1`；`0050_provider_owned_credentials_contract.sql` 只在 effective binding 已唯一写回、defaults 已清空且工作队列静止后，建立 owner-aware FK、每 Provider 一个 live credential 约束并删除空 defaults 表。产品级 active identity partial unique 保留，credential 与 Gateway 历史不改写。
- `0053_rare_lenny_balinger.sql` 只向 `dream_mcp_servers` 增加三个 deny-by-default desired 开关与独立 positive revision，并在 DDL 后发布精确 App settings capability；不触碰凭据、discovery、Sandbox URL 或部署配置。
