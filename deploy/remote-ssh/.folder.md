# deploy/remote-ssh/

## 架构概述

Admin-owned Remote SSH 发布实现；阿里云 ECS 直接使用该路径发布一个包含
Admin/Gateway 与内嵌 PostgreSQL 的容器、Artifact volume，并执行 package
migration、首次真实数据引导、nginx 和回滚。MinIO 与独立 PG 服务不存在。
Provider managed-account 发布固定执行 0047 expand、编译后的 data CLI dry-run/apply、
0048 contract 和 check；任一 gate 失败都不会启动新 Admin。

## 文件清单

| File | Pos | Function |
|------|-----|----------|
| `deploy.sh` | 发布入口 | SSH/rsync、共享网络、单镜像构建、可复用远端 dump 的非交互 import、migration、备份与回滚 |
| `prepare-env.sh` | Secret 配置生成 | 保留现有密钥，生成 mode-0600 ECS env 与 build-only VPC mirror 配置 |
| `docker-compose.yml` | ECS 编排 | 单 Admin/Gateway/PG 容器 + PostgreSQL/Artifact volumes；5432 仅共享网络可达；远端构建默认 1 worker/640MB heap |
| `nginx.conf.template` | Host 代理 | 将独立 Admin 域名代理到 localhost Admin 端口，支持 SSE/长请求 |
| `.env.example` | 配置模板 | 记录生产配置合同，不包含真实 secret |
| `.gitignore` | Secret 边界 | 禁止提交生成的 `.env` |
