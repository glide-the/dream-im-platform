# deploy/nginx/

## 架构概述

SSH 主机直接执行 `pnpm local:stable` 时可复用的 nginx 反向代理模板。
该目录不启动 Admin、数据库或 Docker，也不生成或读取部署密钥。
部署步骤见 [`../../docs/deploy.md`](../../docs/deploy.md)。

## 文件清单

| File | Pos | Function |
|------|-----|----------|
| `ink-memory-admin.conf.template` | Host 代理 | 用显式域名、地址、端口与 ingress 协议代理 Admin/Gateway；保留流式响应、WebSocket，并关闭 Google callback 的参数日志与重试 |
