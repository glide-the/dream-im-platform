# deploy/

Admin SSH 部署统一运行 `pnpm local:stable`。应用和内嵌 PostgreSQL 由专用非 root 服务账户运行；数据恢复、迁移、配置与验证遵循 [部署指南](../docs/deploy.md)。

| 路径 | 职责 |
| --- | --- |
| `README.md` | 部署入口、范围与平台资源索引 |
| `nginx/` | 复用的 Admin 反向代理模板 |
| `systemd/` | 绑定现用 Admin release 的订阅周期推进 service 与 timer 模板 |
| `observability/` | 与应用被动埋点合同配套、部署到服务器管理目录的 ARMS 容量指标适配器 |
| `autodl-ssh/` | 独立 AutoDL/SeetaCloud 平台发布实现 |

旧 `remote-ssh` Docker 发布文件已删除。保留在本机的 ignored secret 不是发布入口，也不得重新纳入 Git。
