# systemd 调度模板

| 文件 | 职责 |
| --- | --- |
| `ink-memory-subscription-periods.service.template` | 使用原运行账户执行周期任务，绑定当前 Admin release 的源码、依赖及私有配置。 |
| `ink-memory-subscription-periods.timer.template` | 按主机配置周期串行触发检查；订阅月度锚点、续期、额度和审计由原订阅服务维护。 |

部署与恢复步骤归[部署指南](../../docs/deploy.md)。任务入口归[运行脚本](../../scripts/run-subscription-period-worker.sh)。
