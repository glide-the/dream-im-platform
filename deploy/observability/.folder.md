# Observability deployment adapter

`capacity-observer.cjs` aggregates actual Node HTTP lifetimes, trusted actor observations, connection pool state and passive domain timings into the existing ARMS Meter. Install only with the matching application hook contract and explicit observation budget. It does not change admission, authorization, billing, payload retention or transaction order. Keep private configuration outside releases and preserve the previous server adapter for rollback.
